# Changelog

## 0.1.1 — 2026-07-27

- Prevent community themes from adding borders or border-like shadows to configured tag labels.

## 0.1.0 — 2026-07-27

- Add configurable tag-to-palette rules.
- Render continuous, vertically centered tag labels in the editor and Reading view.
- Color tagged list bullets while preserving the collapsed-item ring treatment.
- Add coordinated high-chroma light and dark palettes inspired by Tana.
- Support desktop and mobile Obsidian without changing note content.
