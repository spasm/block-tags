# Project-Specific Agent Behaviors

Use this document for durable behaviors the user asks agents to adopt when the rule benefits from examples, rationale, or exceptions. Put concise mandatory rules directly in the user-maintained section of `AGENTS.md`.

For each behavior, capture:

- the behavior and when it applies;
- why the project needs it;
- a good example and, when useful, a counterexample;
- exceptions or escalation conditions;
- the date and source of the user decision.

This file is user-maintained and is never rewritten by `aiify init`.
